## 2026-06-09 - Accessibility pattern for Contact Forms\n**Learning:** Applying `role="status"` and `aria-live="polite"` to form success messages ensures screen readers automatically announce when a form is successfully submitted without causing disruptive focus changes. Using `aria-busy` on buttons along with loading spinners is crucial for communicating async state.\n**Action:** Apply these ARIA attributes to all async forms and feedback messages in the project moving forward.
