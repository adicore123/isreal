## 2024-03-24 - [Accessible Icon-Only FABs & Dynamic Toggles]
**Learning:** Found a specific pattern in the app's floating action buttons (WhatsApp, Phone) and the mobile menu toggle. Icon-only link elements lacked `aria-label` definitions, making their function unclear to screen readers. The mobile menu lacked dynamic `aria-label` and `aria-expanded` attributes which are critical for users to know the state of a menu without visual context. Furthermore, SVG icons within interactive elements were missing `aria-hidden="true"`, causing redundant and noisy screen reader output. Also identified a lack of `focus-visible` styling for these elements, making keyboard navigation difficult to track.
**Action:** When implementing icon-only links or interactive elements (especially FABs or menu toggles), always include descriptive `aria-label` attributes. If it's a toggle, dynamically update the `aria-label` to reflect the current state (e.g., "Open menu" vs "Close menu") and implement `aria-expanded` alongside `aria-controls`. Wrap SVGs in `aria-hidden="true"` to prevent double-reading. Always ensure clear visual focus indicators using Tailwind's `focus-visible` utility classes for proper keyboard accessibility.
